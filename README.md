# Catherine Esther Jones — Cybersecurity Portfolio

A responsive, static portfolio built with HTML, CSS, and vanilla JavaScript. No framework, build command, or paid service is required.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local web server (optional):

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository. A personal site can use the repository name `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root level.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Before publishing

- Confirm the email address and LinkedIn URL in `index.html`.
- Add your GitHub profile URL once you have the profile and repositories ready.
- Review all role dates, tool names, project descriptions, and academic details for accuracy.
- Add public project repositories or write-ups only when they are safe to share and do not expose employer/client information.
- Consider adding a PDF resume link after placing your final resume in this folder (for example, `assets/Catherine-Esther-Jones-Resume.pdf`).

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — visual design, responsive layout, and animations
- `script.js` — mobile navigation, scroll progress, reveal effects, and copy-email action
- `assets/favicon.svg` — custom initials favicon

## Notes

The radar graphic and pipeline illustrations are CSS/SVG-style visual elements, not live monitoring dashboards. Professional case studies are intentionally generalized to avoid disclosing client or employer-sensitive information.
